# Datos procesados

Esta carpeta recibirá archivos generados por el notebook después de aplicar y validar las reglas de limpieza.

Reglas:

- No editar salidas manualmente.
- Cada archivo debe poder regenerarse ejecutando el notebook.
- Registrar filas y totales antes y después de la transformación.
- Los archivos procesados no se versionarán en Git si son grandes.
