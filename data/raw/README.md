# Datos originales

El archivo original `Online Retail.xlsx` fue descargado desde:

https://archive.ics.uci.edu/dataset/352/online-retail

Se conserva aquí sin modificarlo.

La procedencia, fecha de descarga, tamaño y hash SHA-256 están registrados en `source_metadata.json`.

El dataset queda disponible localmente, pero no se versionará en Git por tamaño. Otra persona puede descargarlo desde la fuente oficial para reproducir el análisis.

Debe conservarse la atribución:

> Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33
